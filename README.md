# માતૃશ્રી બંગ્લોઝ – ઇલેક્ટ્રિકલ કામનું કોટેશન (ગુજરાતી આવૃત્તિ)

મૂળ ફાઈલ `GE EST માતૃશ્રી બંગ્લોઝ.docx` (અંગ્રેજી) નો **આબેહૂબ ગુજરાતી અનુવાદ**.

## નવી ફાઈલો

| ફાઈલ | શું છે |
|---|---|
| **GE EST માતૃશ્રી બંગ્લોઝ - ગુજરાતી.docx** | સંપૂર્ણ ગુજરાતી આવૃત્તિ – લેઆઉટ, ટેબલ, રંગ, ફોન્ટ, પેજ-બ્રેક તેમ જ મૂળ ફાઈલના જેવા જ. સંપાદનપાત્ર (Market/દર ભરી શકાય). |
| **GE EST માતૃશ્રી બંગ્લોઝ - ગુજરાતી.pdf** | એ જ લખાણની પ્રિન્ટ/WhatsApp માટે તૈયાર PDF (16 પાનાં, ફોન્ટ embedded). |
| `translation-report.txt` | અનુવાદનો રિપોર્ટ – કેટલા વાક્યો અનુવાદાયા, કઈ બાબતો જાણી જોઈને અંગ્રેજીમાં રાખી (MDB, MCB, CCTV વગેરે), અને QA નું પરિણામ. |

## એક જ આદેશમાં ફરી બનાવવું

```bash
python translate_matrushri.py     # DOCX + PDF + રિપોર્ટ બનાવે છે
python qa_pdf.py merged           # PDF માં દરેક paragraph નું રેન્ડરિંગ ચકાસે છે
```

## અનુવાદ કેવી રીતે થયો

* સ્રોત: `GE EST માતૃશ્રી બંગ્લોઝ.docx` (અંગ્રેજી).
* શબ્દકોશ: પહેલેથી મંજૂર થયેલી બે-ભાષી ફાઈલ
  `GE EST - Bilingual English-Gujarati.docx` માંથી જ લેવામાં આવ્યો છે — એટલે અહીંનું
  દરેક ગુજરાતી વાક્ય પહેલાં મંજૂર થયેલા ગુજરાતી લખાણ સાથે **એકદમ સરખું** છે
  (કોઈ નવો–અલગ અર્થ થાય તેવો અનુવાદ નથી).
* ફક્ત એ જ વાક્યો નવેસરથી ગુજરાતી કરવામાં આવ્યાં જે બે-ભાષી ફાઈલમાં નહોતાં
  (પ્રાઇસિંગ ટેબલની છૂટી લાઈનો, “Ligh Installation”, “Any Other Work” વગેરે), અને એ
  અનુવાદ પણ બાકીના દસ્તાવેજની જ શૈલીમાં છે.
* જાણી જોઈને અંગ્રેજીમાં રાખેલા શબ્દો: MDB, SDB, MCB, RCCB, ELCB, SPD, CAT 6, CCTV,
  DVR, LED, ISI, NDA, AMC, PPE, GST, EV, DTH, UPI, NEFT/RTGS/IMPS, Indian Electricity
  Act 2003, Indian Contract Act 1872, Arbitration and Conciliation Act 1996 — કારણ કે
  આ ટેકનિકલ/કાનૂની સંજ્ઞાઓ ગુજરાતીમાં લખવાથી ઓળખ ખોવાઈ જાય.
* બાકીનું આખું લખાણ – શીર્ષકથી લઈને NDA, શબ્દાવલી, સહી બ્લોક સુધી – સંપૂર્ણ ગુજરાતી છે.

## ફોન્ટ

* DOCX માં ગુજરાતી લખાણ માટે Word ના complex-script ફોન્ટ તરીકે **Nirmala UI** સેટ કરેલો છે
  (Windows/Word માં વ્યવસ્થિત દેખાય; Google Docs/અન્ય જગ્યાએ Noto Sans Gujarati પર fallback થાય).
  દસ્તાવેજની ડિફોલ્ટ ભાષા પણ `gu-IN` કરેલી છે.
* PDF માટે `fonts/` ફોલ્ડરનાં Noto Sans Gujarati + Noto Sans ફોન્ટ જોડીને એક embedded ફોન્ટ
  બનાવાયો છે, એટલે જોડાક્ષરો સાચા પડે છે અને કોઈપણ કમ્પ્યુટર/મોબાઈલ પર એકસરખું દેખાય છે.

## ચકાસણી (QA)

`qa_pdf.py merged` એ દરેક paragraph ને અલગ પાના પર એ જ પહોળાઈમાં દોરી, PDF માંથી પાછું
લખાણ કાઢીને ગુજરાતી અક્ષરો/અંકો સરખાવે છે — હાલનું પરિણામ:

```
કુલ paragraphs ચકાસાયા: 256 | રેન્ડરિંગ ખામીવાળા: 0
```
